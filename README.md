Njangi TrackerA web-based collaborative savings and rotational credit management system designed to eliminate record-keeping discrepancies, track participant reliability, and automate cycle-closing dividend redistribution.
 🎯 Purpose of the ProjectTraditional Njangi (tontine / ROSCA) groups often struggle with manual ledger errors, lack of transparency in member contributions, delayed payments, and complex manual calculations during cycle closings.The primary purpose of Njangi Tracker is to provide an accessible, transparent digital platform that:Replaces error-prone manual ledgers with a real-time web interface.Fosters accountability and financial discipline among members through automated scoring.Simplifies and automates group financial closures, penalty tracking, and dividend payouts.
 🎯 Aims and ObjectivesGeneral AimTo design, implement, and deploy a reliable, full-stack software solution that automates member administration, payment tracking, and rotational cycle resolutions for community savings groups.  Specific ObjectivesDevelop an Interactive Member Management Portal: Provide group administrators with an intuitive dashboard to monitor member enrollment, expected contributions, and current balances in real time.Implement a Dynamic Reliability Metric: Establish a quantitative reliability scoring engine (0–100%) that dynamically adjusts according to individual payment behavior (on-time, partial, or late payments).Automate Dividend Redistribution: Build a dedicated backend algorithm (cycleClosing.py) to systematically redistribute collected group reserves, interest, and penalty pools proportionally among compliant members.Ensure Architectural Integrity & Testability: Apply Object-Oriented software design principles (backed by comprehensive UML use cases, class diagrams, and sequence diagrams) and validate core modules using automated unit tests.  
 🚀 Key Features1. Real-Time Contribution DashboardInstant overview of collective metrics: Total Members, Fully Paid Members, Outstanding Balances, and Total Expected Funds.Live-updating tabular view displaying individual member statuses: Paid, Partial, or Pending.2. Behavioral Reliability ScoringEvery member starts with a baseline reliability score of 100%.Automated deductions occur when partial or delayed payments are recorded, visibly tagged with color-coded status badges (Green, Orange, Red) to incentivize on-time contributions.3. Automated Cycle Closing & Dividend CalculationAlgorithmic distribution of accumulated cycle pools (interest accrued, penalty pools, and extra savings).Eligibility Gating: Filters recipients to only those with complete contributions (Paid) who meet a minimum reliability threshold ($\ge 70\%$).Weighted Sharing: Proportional mathematical allocation based on the member's paid share relative to the collective pool.4. RESTful API ArchitectureClean backend endpoints (/api/members, /api/contributions, /api/cycle/close) allowing seamless integration between the Python backend and asynchronous frontend operations.
 🛠️ Technology StackBackend: Python 3.x, FlaskFrontend: HTML5, Modern CSS3 (CSS Variables, Flexbox/Grid), JavaScript (ES6+ Fetch API)Design & Modeling: Object-Oriented Design (UML Use Case, Class, and Sequence Diagrams)  Testing: Python unittest framework
